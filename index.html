Pen One: What the Watch Is For

analyze-clipboard-monitor monitors the system clipboard for sensitive data shapes, and the pen names the three shapes exactly as the README names them:

  • credit card numbers
  • API keys
  • email addresses

When one appears, it logs a warning and prints an Alert! line.

Alert! Shape at the Gate

The rhythm, without dressing it up: it polls the clipboard once per second and runs until Ctrl+C.

Ctrl+C Ends the Watch.

Pen Two: The Honesty Pen

A Shape Is Not a Verdict

Detection is shape only. The card pattern checks 13 to 16 digits with optional separators and does not run a Luhn check, so innocent long numbers can trip it.

An alert is a prompt to look, not a verdict. A false alarm explained in advance is worth more than a warning that cries certainty.

Pen Three: Setting Up Camp

git clone https://github.com/ShadowGuard-AI/analyze-clipboard-monitor
cd analyze-clipboard-monitor
pip install -r requirements.txt

The only dependency is pyperclip, as requirements.txt records. On Linux a clipboard backend such as xclip or xsel is also needed for pyperclip to reach the clipboard.

Begin the Watch at the working gate.

Pen Four: Working the Gate

python3 main.py [--log-level LEVEL]

The options, entered as a tally:

  • Register Level: --log-level takes one of DEBUG, INFO, WARNING, ERROR, CRITICAL, with INFO as the default
  • -h or --help shows help and exits

The Chart Is Missing: Install pyperclip

If pyperclip is not installed, the tool prints an install message and exits 1 before monitoring starts.
