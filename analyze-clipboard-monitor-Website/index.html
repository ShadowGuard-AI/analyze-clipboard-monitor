analyze-clipboard-monitor

Monitors the system clipboard for sensitive data shapes and alerts the user when one appears: it logs a warning and prints an Alert! line.

Open the repo Usage

What it watches for

  • Credit card number shapes
  • API key shapes
  • Email addresses

It polls the clipboard once per second and runs until Ctrl+C.

The limit, stated in full

Detection is shape only: the card pattern checks 13 to 16 digits with optional separators and does not run a Luhn check, so innocent long numbers can trip it. An alert is a prompt to look, not a verdict.

Install and usage

git clone https://github.com/ShadowGuard-AI/analyze-clipboard-monitor
cd analyze-clipboard-monitor
pip install -r requirements.txt

python3 main.py [--log-level LEVEL]

The only dependency is pyperclip (see requirements.txt). On Linux a clipboard backend such as xclip or xsel is also needed for pyperclip to reach the clipboard. --log-level takes one of DEBUG, INFO, WARNING, ERROR, CRITICAL (default: INFO). If pyperclip is not installed, the tool prints an install message and exits 1 before monitoring starts.
